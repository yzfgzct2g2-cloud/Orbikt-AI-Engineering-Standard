## Purpose

Hold the human-facing guides: how to read the standard, how to adopt it, and how to
maintain it. Everything here is informative — it explains the standard without adding to
it.

Looking for the *rules* for writing documents? Those are normative and live in the meta
layer: [Documentation Specification](../01-meta/documentation-specification.md)
(see [OAES-DEC-004](../50-governance/decisions/dec-004-document-rules-in-meta.md) for why).

## Scope

- Guides for readers, adopters, and maintainers of this standard.

## Non-Scope

- Normative document rules ([01-meta](../01-meta/README.md)).
- Glossary and external references ([71-reference](../71-reference/README.md)).

## Responsibilities

- Keep the guides consistent with the current edition; a guide contradicting a
  specification is defective (ARCH-06).

## Dependencies

- None normative (documentation band, ARCH-06).

## Interfaces

- **Inbound:** read by newcomers after the root README.
- **Outbound:** guides summarize and link the normative layers.
