## Purpose

Hold the shared lookup material: the glossary of defined terms and the register of
external documents the standard refers to.

## Scope

- Glossary and normative/informative external references.

## Non-Scope

- Definitions of requirements (the specifications); guides
  ([70-documentation](../70-documentation/README.md)).

## Responsibilities

- Keep exactly one definition per term (the glossary is the SSOT for terminology,
  DOCU-14) and keep every external reference dated and versioned.

## Dependencies

- None normative (documentation band, ARCH-06); the glossary serves DOCU-14
  informatively.

## Interfaces

- **Inbound:** all documents use terms as defined here; external citations resolve here.
- **Outbound:** none.
